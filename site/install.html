Install

Set up unbake on Windows

One line installs unbake and the tools it needs, and connects it to Claude Code. It shows you what it will do and asks first.

unbake is in its early builds. Expect rough edges and bugs. If something breaks, please open an issue with what you asked and what happened.

What you need

  • Windows 10 or 11
  • FL Studio 2024 or later (tested with FL Studio 25.1). unbake copies sounds from the demo projects that come with it.
  • An AI agent that uses MCP tools, such as Claude Code in the terminal or in VS Code
  • About 4 GB of free space with an NVIDIA card, whose faster version of Demucs is the biggest download, and less without one

Install with your agent

Paste this into Claude Code:

Install unbake: run irm https://qznad.github.io/unbake/install.ps1 | iex in PowerShell, show me the setup plan it prints, and run it once I say yes.

It prints a plan, the agent shows it to you, and nothing is installed until you agree. When it's done, restart Claude Code (in VS Code, run Developer: Reload Window) so it loads unbake.

Or install it yourself

In PowerShell:

irm https://qznad.github.io/unbake/install.ps1 | iex

It shows the same plan and asks Go ahead? [y/N].

What the installer does

  1. Downloads the latest unbake.exe from GitHub Releases into %LOCALAPPDATA%\Programs\unbake, and refuses it unless it matches its published checksum.
  2. Adds that folder to your PATH.
  3. Runs unbake setup, which checks what's already there and offers only what's missing:
    • ffmpeg (opens mp3s) and uv (installs Python tools), with winget
    • Demucs (splits songs into stems), with its GPU version if you have an NVIDIA card
    • Basic Pitch (turns stems into notes)
    • the connection to Claude Code, for every folder you open
  4. Ends with unbake doctor, which says whether each tool works.

Check it works

After restarting Claude Code, ask it:

Do you have the unbake tools? Run the doctor.

Each tool should say ok. Then you're ready for your first loop.

Updating

Run the same line again. It works even while Claude Code is open: the running copy is moved aside, and Claude Code uses the new one after a restart.

Uninstalling

claude mcp remove -s user unbake
uv tool uninstall demucs
uv tool uninstall basic-pitch
Remove-Item -Recurse "$env:LOCALAPPDATA\Programs\unbake"

Then remove %LOCALAPPDATA%\Programs\unbake from your PATH in Windows' environment variables settings. ffmpeg and uv stay, since other programs may use them.

Install by hand

To build unbake from source, for example to work on it:

winget install Microsoft.VisualStudio.2022.BuildTools --override "--wait --passive --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended"
winget install Rustlang.Rustup
git clone https://github.com/Qznad/unbake
cd unbake
cargo build --release
.\target\release\unbake.exe setup

The build tools and Rust take about 5 GB more. setup then installs the rest as above, and connects this build to Claude Code.

Linux and macOS

The listening side and the note-for-note rebuild command run there too, built from source. Reference sounds, sample search and rendering look for FL Studio's Windows install, so they don't work there yet. On those systems, setup lists the install commands for you to run. macOS is untested.
