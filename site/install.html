Install

Set up unbake on Windows

It takes about 15 minutes, most of it downloads. You install a few free tools, build unbake, then connect it to your agent.

A one-line installer is on its way. It will download a ready-made unbake, set up the tools below and connect it to Claude Code for you. Until then, these are the steps.

What you need

  • Windows 10 or 11
  • FL Studio 2024 or later (tested with FL Studio 25.1). unbake copies sounds from the demo projects that come with it.
  • An AI agent that can use MCP tools, such as Claude Code in the terminal or in VS Code
  • About 10 GB of free space, most of it for the C++ build tools and Demucs
  • Optional: an NVIDIA graphics card, which makes splitting a song about 4 times faster

1. Install the tools

Open PowerShell and run these one after the other. They install a C++ build tool and Rust (to build unbake), ffmpeg (to open mp3s), uv (to install Python tools), Demucs (to split songs into stems) and Basic Pitch (to turn stems into notes).

winget install Microsoft.VisualStudio.2022.BuildTools --override "--wait --passive --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended"
winget install Rustlang.Rustup
winget install Gyan.FFmpeg
winget install astral-sh.uv
uv tool install --python 3.11 demucs --with numpy --with soundfile
uv tool install --python 3.10 basic-pitch --with "setuptools<81"
uv tool update-shell

Then close PowerShell and open a new one, so it finds the new tools.

2. Build unbake

git clone https://github.com/Qznad/unbake
cd unbake
cargo build --release

The first build takes a few minutes. Then check everything is in place:

.\target\release\unbake.exe doctor

doctor checks each tool, says what it's needed for and how to fix anything missing. If you have an NVIDIA card, it also gives you the command that makes Demucs use it.

3. Connect it to your agent

Pick a folder to work in, for example Documents\unbake work. Create a file named .mcp.json in it, with the path to your unbake.exe:

{
  "mcpServers": {
    "unbake": {
      "command": "C:/path/to/unbake/target/release/unbake.exe",
      "args": ["mcp"]
    }
  }
}

Use forward slashes in the path. Or, with Claude Code in a terminal, run this once instead:

claude mcp add unbake -- C:/path/to/unbake/target/release/unbake.exe mcp

Open that folder in Claude Code. When it asks whether to use the unbake server, say yes. The server brings its own instructions for the agent, so there's nothing else to install.

4. Check it works

Ask your agent:

Do you have the unbake tools? Run the doctor.

It should list the tools and report each one as ok. Then you're ready for your first loop.

Updating

Close any chat that uses unbake first, since Windows locks a running program. Then:

cd unbake
git pull
cargo build --release

Linux and macOS

The listening side and the note-for-note rebuild command run there too. Reference sounds, sample search and rendering look for FL Studio's Windows install, so they don't work there yet. macOS is untested. Help is welcome: see Contribute.
