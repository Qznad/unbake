Before you start: Claude Code

unbake works through an AI agent. It's built and tested with Claude Code, which runs inside VS Code or in a terminal. You need a Claude plan that includes Claude Code, or an Anthropic API key.

In VS Code

This is how unbake is tested, and the easiest way to follow along.

  1. Install VS Code, then the Claude Code extension from its Extensions panel, and sign in.
  2. Pick a folder to work in, like Documents\unbake work, and open it with File → Open Folder. Claude Code keeps its chats per folder.
  3. Open the Claude Code panel and paste the install line. Claude asks before it runs each command: read it, then allow it.
  4. When setup is done, press Ctrl+Shift+P and run Developer: Reload Window, so Claude Code loads unbake.
  5. Start a new chat and ask "Do you have the unbake tools?". It should list them and run a quick check.

In a terminal

With the Claude Code command line installed, run claude in your work folder and paste the same install line. When setup is done, quit and run claude again.

Working with the agent

  • One chat per song. Start a new chat for a new song, so choices from one song don't carry over to the next.
  • Answer its questions. They often come as choices you can click, and you can always type your own answer instead.
  • Allow unbake's tools. The first time it uses one, Claude Code asks for permission. You can allow them for the whole chat.
  • A whole song is a long session. On a plan with usage limits you may need to pause and come back. Your projects stay in the song's folder either way.

1. Ask for a loop

Give the agent the song and a folder for the project. Use a folder under Documents\Image-Line\FL Studio\Projects\unbake, where FL Studio looks for the project's samples, and a new folder for each song.

Use unbake on C:/Music/my song.mp3, in C:/Users/me/Documents/Image-Line/FL Studio/Projects/unbake/my song. Start with a loop of the drop, then the whole song.

unbake splits the song into stems and listens to it. That takes about a minute with an NVIDIA graphics card, and a few minutes without.

2. Answer what it asks

The agent tells you what unbake heard: tempo, key, length, sections, chords. It also says what unbake isn't sure about. Then it stops and asks you a few things before building anything:

Genre. It suggests one from the tempo and the drums. This decides which FL Studio demo project the sounds come from.
Tempo, when unbake can't tell a tempo from its double or half. Pick the one that feels like the beat when you nod along.
Which part of the song the loop comes from. Usually the fullest drop or chorus.
The reference project and its sounds. Which channels to borrow for the bass, chords and lead, and why.
Kick, snare and hat. unbake compares FL Studio's drum samples with the song's own hits and writes listening clips to a folder in your project. Each set starts with the song's own hit. Play them and pick the closest. Layers of two samples are offered too.

3. Listen to the loop

Before you hear it, the agent renders the loop through FL Studio and compares each part with the song's stems, then fixes what's far off. FL Studio must be closed while it renders, so it asks you to save and close it first.

Then it tells you which .flp to open, and asks three things:

  1. Can you hear every part?
  2. How does it feel overall?
  3. Which part is weakest?

To compare with the song, unmute one of the stem tracks at the bottom of the playlist (Drums, Bass, Other, Vocals stem). They're the song's own parts, cut to the same bars.

You can also change things yourself in FL Studio: notes, sounds, effects, mutes. Save before you answer. The agent reads your saved project and builds the next version on it, as v2, v3 and so on, so you can compare.

4. Agree on the section plan

Once you say the loop works, the agent maps the whole song, part by part, and shows you a plan like this:

SectionBarsDrumsBassLead
Intro1–8ask: behind a filtersilentask: heard once
Drop 19–40reuse the loop'sreusebuild the song's own lines
Break45–48silentreusebuild

Reuse means that part repeats something already built. Build means it's new. Ask means unbake heard it badly, for example a filtered intro or a melody heard only once, so the agent asks you what to do. Every cell says where its evidence comes from.

5. Build the whole song

The agent builds each distinct section as its own short loop, on the sounds of your saved main loop, and you listen to each one the same way. When every section works, it combines them into one project with section markers and the song's stems from bar 1. Then you listen to the whole thing and say what's wrong, section by section.

At the end it explains the song as a short lesson: the key, the chord progression in plain names, what the bass, drums and melody do, and which parts came from the song and which from the reference.

6. Let it work on its own

To watch it build a whole song without stopping to ask you, say so in so many words:

Work on your own from scratch without stopping me.

It then makes every choice itself, from the evidence, and renders and compares after each step until the parts stop getting closer. Keep FL Studio closed for the whole run. At the end it reports which project to open, every choice it made and how sure it was, what got closer and what didn't, and which parts you should check by ear. You can redo any of those choices with it afterwards.

7. Tips

  • Save in FL Studio before you reply. The agent always builds on your latest saved project.
  • Close FL Studio when the agent renders. It can't render while FL Studio is open, and it will ask you.
  • Give each song its own folder. A new run in an old folder can replace projects with the same names.
  • Expect the lead to need your ears. The "other" stem mixes several instruments, so the melody is the hardest part. Leads unbake isn't sure about go on a muted track for you to check against the Other stem.
  • Quiet or filtered intros are heard badly, because a low-pass filter hides most of the sound. unbake can't write automation clips yet, so the agent will tell you how to draw the filter sweep yourself.
  • Numbers aren't taste. The comparisons say whether a part got closer to the song, not whether it sounds good. You decide that.

Without an agent

rebuild needs no agent. It writes a note-for-note project straight from what unbake heard: one pattern per part over the whole song, sounds cut from the stems, MIDI files and a report. It's more literal and messier than an agent's project.

.\target\release\unbake.exe rebuild "C:\Music\my song.mp3" -o "$HOME\Documents\Image-Line\FL Studio\Projects\unbake\my song"

unbake --help lists every command, and each one has its own --help.

unbake is for studying music. Its projects hold the song's own stems, so only share or release what you have the rights to.
