For FL Studio on Windows · early and open source

Turn a song into an FL Studio project you can learn from.

Give unbake an mp3. It splits the song into stems and works out its tempo, key, chords, drum groove, bass line and melody. Then an AI agent such as Claude Code builds an editable FL Studio project from what it heard: the song's parts, played on sounds from real producers' projects, with the song's own stems underneath to compare.

Get started See an example

Early builds. unbake is at version 0.1 and still has a long way to go. Tempo, key, chords, bass lines and drum grooves usually come out right. The lead melody is often wrong, filter sweeps and fades can't be written yet, and you will run into bugs. Think of what it makes as a starting point to learn from, not a finished copy of the song.

Get started

unbake runs on your computer, next to FL Studio. One line installs it. After that, you just talk to your agent.

1 · Install

Paste this into Claude Code:

Install unbake: run irm https://qznad.github.io/unbake/install.ps1 | iex in PowerShell, show me the setup plan it prints, and run it once I say yes.

Or run it in PowerShell yourself:

irm https://qznad.github.io/unbake/install.ps1 | iex

It lists what's missing and asks before installing anything. Then restart Claude Code so it loads unbake.

2 · Ask for a loop

Give it a song you want to understand:

Use unbake on C:/Music/my song.mp3. Start with a loop of the drop.

It tells you what it heard, then asks you a few things: the genre, which part of the song, which drum sounds are closest.

3 · Listen in FL Studio

Open the project it writes. Play it, then unmute a stem track to hear the song's own part.

Tell the agent what's weakest, or change it yourself and save. It builds the next version on yours, and then the whole song, one section at a time.

The guide walks through every step.

Needs Windows 10 or 11, FL Studio 2024 or later, and Claude Code or another agent that uses MCP tools. Install details

An 8th-note tune where every note gets a quick answer a 16th later: an octave lower over Gm11 and B♭maj9, a fifth lower over Am

The loop an agent built with unbake

Same 8 bars, same tempo, same loudness. The loop plays the song's drums, bass, chords and arpeggio lead on sounds copied from Ephixa's "Club Penguin", one of FL Studio's demo projects, with a kick and snare picked by how close they sound to the song's own.

The lead, as unbake heard it (bars 5–12)

The song repeats this 8-bar line six times. unbake keeps the 121 notes its repeats agree on, so a note that one repeat hides behind another instrument still shows up. That pattern, an octave down over the first two chords and a fifth down over Am, is the kind of thing worth learning from a song.

The loop in FL Studio

From the song

  • the tempo, key and section layout
  • the chords and where they change
  • the bass line, the drum groove and the lead tune
  • the stems, cut to the same bars, on muted tracks

Not from the song

  • every sound and effect, copied from FL Studio's demo projects by real producers
  • the mix: levels are set by ear and by comparing renders
  • anything unbake couldn't hear clearly, which the agent asks you about

How it works

unbake runs on your computer and does the listening and the file writing. The agent does the musical choices, and you listen.

  1. Split

    Demucs separates the song into drums, bass, other and vocals.

  2. Listen

    unbake finds the tempo, key, sections, chords and drum hits, and Basic Pitch turns the bass and other stems into notes. Each result says how sure it is.

  3. Build

    The agent picks a reference from FL Studio's demo songs, copies its sounds and effects, and writes the song's parts. Drum samples are chosen by how they sound next to the song's own hits.

  4. Check

    unbake renders the project through FL Studio and compares each part with its stem. The agent changes one thing at a time and keeps it only if the part got closer.

  5. You steer

    The agent stops to ask you: the genre, the sounds, how each loop sounds. Or ask it to work alone and report every choice.

What you get

  • a .flp with the song's tempo and section markers
  • a pattern for each part and section, with names you can read
  • channels copied from FL Studio's demo projects, with their plugin, preset and mixer effects
  • the song's drums, bass, other and vocals stems as muted audio clips
  • the agent's notes on each choice: chord names, what repeats, what it wasn't sure about

Where it stands

  • Tempo, key, sections, chords, drum grooves and bass lines are usually right.
  • Projects open cleanly in FL Studio, with every sample found.
  • The lead melody is often wrong when several instruments play at once.
  • Filter sweeps and fades need automation clips, which unbake can't write yet.
  • It assumes 4/4 on a straight grid, and it's been tested mostly on electronic instrumentals.
